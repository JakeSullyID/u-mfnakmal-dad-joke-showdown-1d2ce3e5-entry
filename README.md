# Dad Joke Showdown

This repository contains our official entry for the make.fun bounty "Dad Joke Showdown", implemented as a lightweight Node 22 program that outputs a single original dad joke to entry.txt with zero external dependencies, complete determinism, and no network access. Delivering maximum comedic punch with absolute minimalism is the entire essence of victory in this contest.

## How to run

Execute the program using Node 22 with the following command:

```bash
node main.ts
```

You can optionally specify a custom output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable.
